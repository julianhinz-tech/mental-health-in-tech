# Mental-health-in-tech

This Jupyter notebook explores responses from the 2016 OSMI Mental Health in Tech Survey. It uses K-Means to group respondents by their reported experiences of workplace mental health support and barriers, and PCA to visualize the groups. The clusters were weakly separated and should be interpreted as exploratory profiles.

## How to run

1. Download the .ipynb file from this repository.
2. Download the ZIP from the OSMI Mental Health in Tech Survey 2016 dataset page (https://www.kaggle.com/datasets/osmi/mental-health-in-tech-2016).
3. Create a folder named data next to the notebook. Save the downloaded ZIP in that folder as archive.zip. Leave it zipped so the notebook can read data/archive.zip.
4. Use a Python environment with pandas, numpy, matplotlib, and scikit-learn installed. Open the notebook in Jupyter and run all cells from top to bottom.
